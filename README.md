# 🍎 AI-Powered Fruit Quality & Shelf-Life Prediction System

A complete end-to-end Deep Learning project that classifies fruit/vegetable quality
(fresh / medium / rotten) from images and estimates remaining shelf life — built with
**TensorFlow/Keras (MobileNetV2)**, a **FastAPI** backend, and a **Streamlit** frontend.

## ⚡ Quick Start

### 1. Install dependencies

```bash
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Download the dataset

Download from Kaggle:
[https://www.kaggle.com/datasets/graviton17/fruit-and-vegetable-quality-levelwise-dataset](https://www.kaggle.com/datasets/graviton17/fruit-and-vegetable-quality-levelwise-dataset)

Extract so the structure looks like:

```
dataset/
    fresh_apple/     *.jpg ...
    rotten_apple/    *.jpg ...
    fresh_banana/    *.jpg ...
    ...
```

### 3. Train the model

```bash
# Default: MobileNetV2, 20 epochs
python train.py --dataset dataset/

# ResNet50 backbone with fine-tuning
python train.py --dataset dataset/ --model resnet50 --epochs 25 --finetune
```

Training artefacts are saved to `logs/` and `model/`.

### 4a. Run inference (CLI)

```bash
# Single image
python predict.py --image path/to/apple.jpg --visualise

# Batch folder → CSV
python predict.py --folder path/to/images/ --output results.csv
```

### 4b. Start the FastAPI backend

```bash
uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```

Swagger UI → [http://localhost:8000/docs](http://localhost:8000/docs)

### 4c. Launch the Streamlit app

```bash
streamlit run app.py
```

Opens at [http://localhost:8501](http://localhost:8501)

## 🏗️ Architecture

```
Input Image (224×224×3)
       │
       ▼
Augmentation Layers  (rotation, zoom, flip, brightness) ← training only
       │
       ▼
MobileNetV2  (frozen backbone, ImageNet weights)
       │
       ▼
GlobalAveragePooling2D
       │
       ▼
Dense(256) → BatchNorm → ReLU → Dropout(0.4)
       │
       ▼
Dense(128) → BatchNorm → ReLU → Dropout(0.3)
       │
       ▼
Dense(num_classes, Softmax)
```

## 📊 Evaluation Outputs

After training, the following artefacts are saved in `logs/`:

- `class_distribution.png` — bar chart of per-class sample counts
- `sample_images.png` — grid of sample images per class
- `training_curves.png` — accuracy & loss across epochs
- `confusion_matrix.png` — heatmap of true vs predicted labels
- `classification_report.txt` — precision / recall / F1 per class
- `training_log.csv` — epoch-by-epoch metrics

## 🛠️ Training Tips

- **GPU strongly recommended** — training on CPU will be very slow.
- Use `--finetune` after initial convergence to squeeze extra accuracy from the backbone.
- If your dataset is heavily imbalanced, consider class weights (see `train.py` comments).
- Increase `--epochs` if validation accuracy is still improving at the cutoff.
